# ABDOU RAPID — Motorcycle Delivery

موقع تعريفي وبطاقة رقمية لخدمة توصيل بالدراجة النارية، جاهز للنشر على GitHub Pages.

## الملفات
- `index.html` — بنية الصفحة ومحتواها.
- `style.css` — التصميم المتجاوب.
- `script.js` — بيانات الخدمة وأزرار الاتصال وWhatsApp وإنشاء QR.

## تعديل معلومات الخدمة
افتح `script.js` وعدّل القيم داخل كائن `BUSINESS` فقط:
- `serviceName`
- `owner`
- `phoneDisplay`
- `phoneInternational`
- `whatsapp` (أرقام فقط مع رمز الدولة، من دون + أو مسافات)
- `coverage`
- `hours`
- `message`

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub، مثلاً `abdou-rapid`.
2. ارفع الملفات الثلاثة `index.html` و`style.css` و`script.js` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages. غالباً سيكون بالشكل:
   `https://USERNAME.github.io/abdou-rapid/`
7. افتح الرابط من هاتفك وتأكد من ظهور الصفحة وعمل أزرار الاتصال وWhatsApp.

## إنشاء QR النهائي
- رمز QR يُنشأ تلقائياً من عنوان الصفحة الحالي؛ لذلك بعد النشر افتح رابط GitHub Pages النهائي.
- انتقل إلى قسم QR Code واضغط **تحميل PNG** أو **تحميل SVG**.
- لا تحمّل الرمز من معاينة محلية قبل النشر؛ ففي هذه الحالة قد يشير إلى عنوان محلي أو غير صالح للزبائن.
- اختبر الرمز النهائي بكاميرا هاتف قبل طباعته.

## ملاحظات
- المشروع لا يحتاج إلى قاعدة بيانات أو Backend.
- مكتبة QR تُحمّل من jsDelivr، لذلك يلزم اتصال بالإنترنت عند فتح الصفحة لأول مرة لإنشاء الرمز.
- الموقع لا يتتبع الطلبات ولا يستقبلها في قاعدة بيانات؛ زر الطلب يفتح محادثة WhatsApp برسالة جاهزة.
- ساعات العمل ومنطقة التغطية والنصوص قابلة للتعديل من `script.js`.
